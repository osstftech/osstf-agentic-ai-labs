# OSSTF Agentic AI Labs

Public companion labs for the OSSTF Agentic AI video series.

**Status: repository initialized; executable labs are not published yet.**

Learn the concepts behind controlled tool execution, scoped retrieval, session state, reliability and agent evaluation through small Google ADK examples in **Java, Python and JavaScript**.

These examples are separate from the OSSTF Tutor production application. ADK is used for concept demonstrations and testing; it is not an OSSTF Tutor production dependency.

## Start here

1. Read the [learning roadmap](docs/learning-roadmap.md).
2. Choose a [language track](labs/README.md).
3. Follow a lab only when its README includes verified setup, tests and expected results.

A concept-lab test does not establish that the production portal passes its own integration or security tests.

## Planned concepts

Tool contracts; identity-aware authorization; selected-book/topic retrieval; routing and execution limits; owned session state; streaming/retry recovery; evaluation and regression.

## Data and safety

Use fictional content and synthetic users. Do not submit credentials, private projects, student information, paid book manuscripts or private production architecture in commits, issues or pull requests. Routine tests should run without paid model access; optional live runs must explicitly state model, configuration and cost considerations.
